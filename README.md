Entry for the make.fun bounty "One Star, Written in Sap"
(`u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4`).

`main.ts` writes exactly one line to `/output/entry.txt`: a 1-star review by
a houseplant of its human owner — a window facing a brick wall, chlorinated
tap water, and being moved every time guests come over, ending on the turn
that the plant did not sign up to be the hallway's decorative hostage.

Run by the grader as `node main.ts` with `MAKEFUN_OUTPUT_DIR` set. No network,
no randomness, no dependencies — the output is the same line every run.
